# AgentsDemo

Шаблон игры на Pygame, где агент учится находить «еду» (зелёные квадраты) по радару. Управление — через диспетчер: случайное блуждание или Keras-нейросеть, с накоплением опыта и периодическим переобучением.

## Что происходит в игре

- Красный квадрат — агент, зелёные — цели (еда).
- У агента есть **радар**: круговой обход лучами, расстояние и цвет (еда / стены), с затуханием по дальности.
- Опыт пишется в историю (шаги и попытки до еды или таймаута). Удар о стену даёт **боль**: разворот от стены и отрицательный пример для обучения.
- **Диспетчер** стартует с `neural` и переключает на `random` только если долго не находит еду; после успеха/обучения снова предпочитает нейросеть.
- Нейросеть учится на **положительных** (дошёл до еды) и **отрицательных** (не дошёл) примерах; на входе — окно из нескольких шагов радара и прошлых действий.

Окна при запуске AI-режима: игра, графики радара (RGB), дашборд режимов и статистики.

## Установка

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Зависимости: `pygame`, `numpy`, `tensorflow` (Keras).

При ошибках SSL у pip:

```bash
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt
```

## Запуск

```bash
python main.py
```

В `main.py`:

- `CONTROL_MODE = CONTROL_AI` — агент + диспетчер + нейросеть  
- `CONTROL_MODE = CONTROL_KEYBOARD` — управление стрелками  

Агент по умолчанию: `NeuralFoodAgent`.

## Архитектура

| Модуль | Роль |
|--------|------|
| `game.py` | Игровой цикл, коллизии, окна |
| `player.py` / `keyboard_player.py` | Игрок (ИИ / клавиатура), общий `BasePlayer` + радар |
| `radar.py` / `radar_view.py` | Радар и окно RGB-графиков |
| `engine.py` | Исполнение действий (сдвиг красного квадрата) |
| `behaviors.py` | `Behavior`: `RandomWalkBehavior`, `NeuralBehavior`, `TrainingBehavior` |
| `dispatcher.py` | Выбор текущего поведения, переключение при «застое» |
| `experience.py` | Шаги, попытки (`Attempt`), буфер опыта |
| `nn_model.py` | Keras-политика: история → направление |
| `agents.py` | `NeuralFoodAgent` — опыт, обучение, очистка буфера |
| `dashboard.py` | Дашборд: режим, опыт, train, cleanup |
| `config.py` | Константы игры, радара, NN, диспетчера |

Поток в AI-режиме:

```text
радар → признаки (история) → Behavior (random/NN)
     → Engine → движение → еда? → Experience / Attempt
     → при необходимости Training → снова neural
```

## Поведения

- **Random walk** — случайное направление ↑↓←→, одно и то же действие на 1…10 шагов (`RANDOM_WALK_*` в `config.py`). Без «стоять».
- **Neural** — Keras: вход = `HISTORY_LEN` кадров (радар + прошлые действия), выход = направление; действие «липкое» (`NEURAL_STICKY_STEPS` + порог смены), чтобы не шататься.
- **Training** — на время `fit` то же блуждание; после обучения буфер частично очищается (`EXPERIENCE_KEEP_FRACTION`).

Переключение: старт с neural; neural → random при `DISPATCH_STALE_ATTEMPTS` неудач подряд; с random обратно на neural после еды или при следующем застое / после обучения.

## Обучение

- Сэмплы из **успешных** (+) и **провальных** (−) попыток.
- Дообучение после набора еды (`TRAIN_EVERY_N_FOODS`) и при достаточном числе сэмплов (`TRAIN_MIN_SAMPLES`).
- После `fit` диспетчер снова включает нейросеть.

Основные ручки — в `config.py` (радар, сеть, диспетчер, блуждание, обучение).
